# Raw ability sources

Unmodified upstream files that abilities in `data/data.json` were built from,
kept so each imported ability can be checked against its original.

Generated by `scripts/import_abilities.py`; do not edit by hand. Each folder is
rebuilt on every import run and holds only the files that produced an ability
that survived deduplication.

| Folder | Upstream | License |
|---|---|---|
| `forgearmory/` | facebookincubator/ForgeArmory | MIT |
| `leonidas/` | ReversecLabs/leonidas | MIT |
| `stratus-red-team/` | DataDog/stratus-red-team | Apache-2.0 |
| `purplesharp/` | mvelazc0/PurpleSharp | BSD-3-Clause |

Each folder contains:

- the upstream files at their original paths;
- the upstream `LICENSE`;
- `manifest.json`: the repository URL, the commit the files were taken from,
  and for each file the IDs of the ability rows built from it.

To verify an ability, find its ID in a `manifest.json`, open the listed file,
and compare it with the row in `data/data.json` (the row's description also
ends with `Source: <library> <path>`).
